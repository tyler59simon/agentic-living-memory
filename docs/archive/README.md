# Archive

These files are historical records. They describe code as it was when they were written, and nothing here is kept current.

- `notebooks-design.md`: the Notes Studio notebook design (NS-2A, NS-2B). Hosted notebooks were retired in CON-18 on 2026-11-24; [NOTEBOOKS.md](../../NOTEBOOKS.md) describes folder notebooks as they are now.
- `ns2a-codex-review.md` and `ns2b-codex-review.md`: the Codex reviews of NS-2A and NS-2B, with each finding and its fix.
- `sqlite-vec/`: the raw results, baseline and write-up behind [the sqlite-vec evaluation](../evaluations/sqlite-vec/README.md).
